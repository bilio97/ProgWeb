## SKIFREE

O jogo consiste em descer a montanha desviando dos obstáculos usando os comandos:

```
Seta para esquerda para desviar para diagonal esquerda;
Seta para direita para desviar para a diagonal direita;
F para aumentar a aceleração do esquiador, o padrão é de 20m/s e acelerado é de 30m/s.

Caso o jogador tropece em algum obstáculo perderá uma vida;
Para recuperar vidas é necessário coletar o cogumelo;
Se o contador de vidas zerar, o jogo acaba e a página precisa ser atualizada.
```
